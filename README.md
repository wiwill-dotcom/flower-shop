# Лепесток

Локальный визуальный прототип магазина цветов на Next.js, TypeScript и Tailwind CSS.

## Запуск на этом компьютере

```powershell
.\start.cmd
```

Откройте http://127.0.0.1:3000. В проекте подготовлен локальный Node.js, глобальная установка не требуется.

Если Node.js и npm уже установлены, можно использовать `npm install` и `npm run dev`.

## Проверка

`npm run build` проверяет типы и создаёт статический сайт в `out/`.

В приложении нет серверной логики, базы данных, авторизации и оплаты. Подключён только клиентский Telegram WebApp API. Локальный сервер Next.js используется только для просмотра интерфейса. Корзина хранится в памяти вкладки и сбрасывается при обновлении. Кнопка оформления показывает сообщение о демоверсии и не отправляет данные.

Названия, цены и состав букетов — тестовые. Источники демонстрационных фотографий перечислены в `IMAGE_SOURCES.md`.

## Vercel

Загрузите исходники в GitHub вместе с `package-lock.json`, `vercel.json` и всей папкой `public`. На Vercel выберите Add New → Project → Import для этого репозитория → Deploy. Корень проекта — папка с `package.json`, Framework Preset — Next.js. Переменные окружения не нужны. Команды установки и сборки заданы в `vercel.json`, Node.js 22.x — в `package.json`. Оставьте Output Directory по умолчанию: Vercel распознаёт статический экспорт Next.js. Команда `npm start` для статического экспорта не используется.

Изображения поставляются из `public/images` по относительным адресам `/images/...` и копируются в `out/images` при сборке. Публикация не требует доступа к сайтам-источникам фотографий.

## Telegram

Официальный SDK: https://core.telegram.org/bots/webapps. Он подключён в корневом layout до гидратации React. `TelegramProvider` вызывает `ready()` и `expand()` только при Telegram-запуске. Наличие SDK само по себе не означает запуск внутри Telegram.

В клиентских компонентах: `import { useTelegram } from '@/hooks/useTelegram'`. Hook возвращает `telegramUser`, `initData`, `colorScheme`, `isTelegram`, `webApp` и `theme` с полями `backgroundColor`, `textColor`, `hintColor`, `buttonColor`, `buttonTextColor`. `telegramUser` берётся из `initDataUnsafe.user`; данные не проверены, не отправляются и не сохраняются. Ни `isTelegram`, ни данные пользователя не подходят для авторизации или проверки заказа.

События темы и safe area обновляют интерфейс без перезагрузки, обработчики снимаются при размонтировании. Тема Telegram применяется только к нижней навигации, сохраняя оформление каталога. Отступы учитывают Telegram и iOS `env(safe-area-inset-*)`. В обычном браузере сохраняется исходная палитра; при отсутствии SDK приложение продолжает работать.
